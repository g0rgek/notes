
# Определение
VACUUM — это команда обслуживания базы данных, которая очищает таблицы от «мёртвых строк» (dead tuples).  

**Мёртвые строки** — это старые версии записей в таблице, которые больше не актуальны, но физически всё ещё хранятся на диске. Они появляются из-за механизма MVCC: при `UPDATE` и `DELETE` старые версии строк не удаляются сразу.  

VACUUM:
- освобождает место внутри таблиц;
- предотвращает разрастание (bloat);
- поддерживает корректную видимость данных;
- помогает оптимизатору запросов (в связке с ANALYZE).
# Зачем он нужен
Без регулярного VACUUM:
- таблицы и индексы раздуваются;
- запросы начинают работать медленнее;
- может закончиться пространство из-за переполнения ID транзакций.
# Как запустить
- **Обычный VACUUM (без блокировок):**
```
VACUUM; VACUUM table_name;
```

- **VACUUM с обновлением статистики:**
```
VACUUM ANALYZE;
```

- **Полная очистка (агрессивная):**
```sql
VACUUM FULL;
```
