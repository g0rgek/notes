# Cross Join
Все возможные комбинации соединения строк двух таблиц. Декартово произведение:
```
t1   t2        id|id
id   id        -----
---  --- -->   1  4
1     4        1  5
2     5        2  4
3              2  5
               3  4
			   3  5
```
# Inner Join
Это все комбинации соединений строк с неким фильтром `condition`. 

Конструкция
```sql
t1 INNER JOIN t2 ON condition
```

эквивалентна
```sql
t1 CROSS JOIN t2 WHERE condition
```

```sql
select nums from t1;
 nums
------
    1
    1
    3

select nums from t2;
 nums
------
    1
    1
    4
    5

select t1.nums, t2.nums from t1 inner join t2 on t1.nums = t2.nums;
 nums | nums
------+------
    1 |    1
    1 |    1
    1 |    1
    1 |    1
(4 rows)
```
# Left Join
Это тоже самое что и INNER JOIN (т.е. все комбинации соединений строк, отфильтрованных по какому-то условию), и плюс еще записи из левой таблицы, для которых в правой по этому фильтру ничего не совпало.
```sql
select nums from t1;
nums
----+
1
1
3

select nums from t2;
nums
----
1
1
4
5

select t1.nums, t2.nums from t1 left join t2 on t1.nums = t2.nums;
 nums | nums
------+------
    1 |    1
    1 |    1
    1 |    1
    1 |    1
    3 |
```

**LEFT JOIN** можно переформулировать так:
```sql
SELECT *
FROM t1
	CROSS JOIN t2
	WHERE t1.nums = t2.nums
UNION ALL
SELECT t1.nums, null
FROM t1
WHERE NOT EXISTS (
	SELECT
	FROM t2
	WHERE t2.nums = t1.nums
);
```
# Right Join
Работает как и Left Join, но добавляет строки из правой таблицы для которых нет совпадений:
```sql
select t1.nums, t2.nums from t1 right join t2 on t1.nums = t2.nums;
 nums | nums
------+------
    1 |    1
    1 |    1
    1 |    1
    1 |    1
      |    4
      |    5
```
# Full Outer Join

```sql
select * from t1 full outer join t2 on t1.nums = t2.nums;
 id | nums | id | nums
----+------+----+------
  1 |    1 |  1 |    1
  1 |    1 |  2 |    1
  2 |    1 |  1 |    1
  2 |    1 |  2 |    1
  3 |    3 |    |
    |      |  3 |    4
    |      |  4 |    5
```
- соединяет строки **по условию `ON`**
- сохраняет **все строки из обеих таблиц**
- где нет пары → `NULL`
