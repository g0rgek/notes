# Чтение
1. Спрашиваем того, кто пришел с проблемой, какие шаги предпринимал
2. Смотрим на графики и метрики:
	- закончилось место на диске(дикий своп) - добавить дисковой памяти
	- слишком долго создаются подключения - расширить пул подключений
	- база долго отвечает - перенести её на сервер другого провайдера
	- недавно был релиз - откатить его
3. Если не помогли простые решения:
	- EXPLAIN - план запроса
	- EXPLAIN ANALYZE - покажет план и выполнит запрос
	- Оптимизировать запросы
	- Добавить (покрывающие) [индексы](./Индексы.md)
4. После оптимизации БД:
	- добавить кеширование (на уровне БД, потом внешний)
	  `effective_cache_size(50-75% from RAM)`
	- добавить ресурсов CPU/RAM/DISC
5. Масштабировать БД:
	- репликация
	- шардирование
6. Изменить архитектуру (денормализация, CQRS)
