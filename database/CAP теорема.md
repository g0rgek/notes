## Как связаны CAP и изоляции транзакций
НИКАК! Это не связанные вещи. Изоляция транзакций применима к отдельному инстансу БД. CAP-теорема - к распределенной БД.

САР-теорема ставит нас перед выбором: если сеть между мастером и репликой обрывается, но сами по себе сервера доступны, то мы можем:
- Выбрать доступность и отдавать из реплики данные (но возможно неконсистентные)
- Не отдавать данные из реплики, теряя доступность (отдавать 500)
Т.е. мы выбираем либо **ДОСТУПНОСТЬ** либо **КОНСИСТЕНТНОСТЬ**.
```
    |               ^
    | write         |read
	V               | 
+--------+       +-------+
|        |       |       |
| MASTER |--XXX->| Slave |
|        |       |(alive)|
+--------+       +-------+
```
