# 1. Singleton (глобальная одиночка)
Гранатия, что у класса есть только единственный экземпляр. Предоставляет глобальный доступ к нему.
подключение к БД 
# 2.  Factory (Фабрика)
СОздает объекты без указания их конкретный типов
создание транспорта
# 3.  Builder (Строитель)
Позволяет пошагово создавать сложные объекты пошагово
Pool.WithAddrs().WithCreds()...
# 4.  Adapter (Адаптер)
Преобразует интерфейс одного класса в интерфейс, ожидаемый клиентом
адаптация легаси логера
# 5.  Strategy (стратегия)
Позволяет выбирать алгоритм в зависимости от контекста
алгоритм балансирования нагрузки
# 6.  Observer (Наблюдатель)
Уведомление подписчиков об изменениях в объкте
новостная рассылка
