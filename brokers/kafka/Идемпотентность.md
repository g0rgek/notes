```
            create order
+--------+  idempotency_key = 123   +--------+
| client |------------------------->| server |
+--------+ <----------------------- +--------+
```

При отправке запроса к серверу, к сообщению присваивается ключ идемпотентности. Если сервер не ответил после запроса, то клиент отправит это сообщение еще раз. И сервер увидит, что сообщение с таким же ключом - не будет заново его обрабатывать и ответит клиенту ОК.
