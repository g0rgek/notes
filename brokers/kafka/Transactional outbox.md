
Паттерн для продюсера, который пишет в Кафку.

**Что это такое:**  
Способ **надёжно публиковать события в Kafka без синхронных вызовов**, сохраняя консистентность данных. Паттерн добавляет два компонента, чтобы гарантировать согласованность между изменениями данных и отправкой событий в распределённых системах: таблицу outbox (Outbox Table) и relay-процесс (Relay Process).

1. **Order Service в рамках ОДНОЙ транзакции БД записывает:**
    - бизнес-данные (например, `order = CREATED`)
    - запись в таблицу **outbox** (например, событие `OrderCreated`

| id         | UUID               | Уникальный id события                      |
| ---------- | ------------------ | ------------------------------------------ |
| event_type | STRING             | Тип события (OrderCreated)                 |
| payload    | JSON               | Сериализованное тело события               |
| created_at | TIMESTAMP          | Время сохранения события                   |
| sent_at    | TIMESTAMP NULLABLE | Время отправки события                     |
| status     | TEXT               | Статус (создано/отправлено/инвалидировано) |
Объединяя обе записи в одну транзакцию, мы гарантируем, что либо выполнятся обе операции, либо обе будут отменены — это обеспечивается ACID-свойствами транзакций (атомарность, согласованность, изоляция, устойчивость).

2. **Транзакция коммитится один раз.**  
    Либо сохранилось всё, либо ничего — рассинхрона нет.
3. **Фоновый процесс(consumer) читает outbox-таблицу.**
    - Забирает новые записи
    - Публикует их в **Kafka**
    - Помечает как отправленные (или удаляет)
```sql
	SELECT * FROM outbox
	WHERE sent_at IS NULL
	ORDER BY created_at
	LIMIT 10
	FOR UPDATE SKIP LOCKED;
```
	
4. **Analytics Service читает события из Kafka асинхронно.**
    - Долгая обработка больше никому не мешает
    - Таймаутов в Order Service нет
#### Почему это хорошо работает с Kafka
- At-least-once + идемпотентные консьюмеры = безопасные ретраи
- Нет связности между сервисами
- Решается проблема «в БД закоммитилось, а сообщение не ушло»
