
**Топик** - таблица в БД.

**Партиция** - шард таблицы. Для каждой партиции может быть свой consumer.
Каждая партиция гарантирует порядок сообщений (локальная упорядоченность).
Для того, чтобы писать в одну и ту же партицию, нужно правильно выбрать ключ партиционирования (id заказа).

Ключ партиционирования должен быть таким, чтобы сообщения равномерно разбивались по партициям.
